# Egrysa v0.1.0-alpha.7

An evaluation release for non-production environments, not a certification or production-readiness
claim.

## What changed since alpha.6

- **Standalone binaries.** Each release carries a self-contained executable for macOS and Linux on
  arm64 and x86-64, with the gateway's permissions compiled in and the example configurations packed
  beside it, hashed into the signed `SHA256SUMS`.
- **Homebrew and npm.** Both install that binary and pin its hash from the signed manifest. The
  Homebrew formula is served from this repository. See `docs/INSTALL.md`.
- **`egrysa --version` and `egrysa --help`**, which answer without reading configuration or opening
  a port.
- **Task quality, measured for the first time.** On an 8B local model the default sentinel
  surrogates cost 43% of the baseline pass rate, because the model damages the token and the gateway
  fails closed; `policy.surrogates.style: synthetic` brings that to 10%, all of it one case where
  the answer depends on the ordering of a transformed value. If your workload asks the model to
  repeat or act on values, use synthetic surrogates.
- **Penetration test scope** published at `docs/PENTEST_SCOPE.md`.
- A flaky group-commit test now measures the code rather than the runner's disk.
- Updated distroless base image and CI actions.

## Scope

Egrysa does not guarantee detection of every sensitive value, prove provider deletion or retention
behavior, or make an organization compliant. Person names and physical addresses need the
off-by-default NER sidecar. The Azure, Bedrock, and Vertex adapters, the remote signer against a
real HSM or KMS, and an external identity provider have been tested against in-process stand-ins,
not live services. Independent corpus review and a penetration test are outstanding. The macOS
binaries are ad-hoc signed, not notarized by Apple.
